# Ámbito `@ing-electrica`

Colección de paquetes oficiales para la Escuela Profesional de Ingeniería Eléctrica de la Universidad Nacional de San Agustín de Arequipa (UNSA).

## Paquetes Disponibles

1. [`@ing-electrica/tif-theming`](file:///home/cricro/store/projects/UNSAReport/packages-extra/ing-electrica/tif-theming/)
   - Variables de diseño, fuentes, márgenes institucionales (3.0 cm para empastado/encuadernación) y geometría de página para Trabajos de Investigación Formativa.
2. [`@ing-electrica/tif`](file:///home/cricro/store/projects/UNSAReport/packages-extra/ing-electrica/tif/)
   - Plantilla completa y componentes para la elaboración del Perfil de Trabajo de Investigación Formativa (TIF), portada institucional estandarizada, tabla de contenidos automatizada, y contenidos basados en el manual oficial de redacción.
