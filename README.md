# UNSAReport Packages Extra

Colección de paquetes y scopes secundarios y específicos para el ecosistema [UNSAReport](https://github.com/UNSAReport).

A diferencia de los paquetes bajo el scope principal `@unsareport` (mantenidos activamente de forma centralizada), este repositorio alberga colecciones de plantillas y temas que tienen un ciclo de vida independiente o menor frecuencia de actualización.

## Estructura de Scopes

- [`@unsareport_ing-electrica`](unsareport_ing-electrica/): Escuela Profesional de Ingeniería Eléctrica (UNSA).
